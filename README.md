# Guess the Number

A responsive number-guessing game built with HTML, CSS, and JavaScript.

## Features

- Random number generation
- Multiple answer choices
- Score tracking
- Streak tracking
- Best-score persistence
- Local storage
- Responsive design
- Sound effects

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

- DOM manipulation
- Event listeners
- Functions
- Loops
- Random number generation
- Local storage
- UI state management
- Responsive CSS
